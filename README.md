# Iris Classification

Decision Tree classifier on the classic Iris dataset. Saves a scatter plot (`iris_scatter.png`).

## How to run
```bash
pip install -r requirements.txt
python iris_classification.py
```

## Requirements
- scikit-learn
- matplotlib
- numpy
